# broken-link-checker-fixture

A tiny static test site used by the Broken Link Checker Apify Actor for its automated daily test.

It has three plain HTML pages, working internal links, one deliberately broken link (a 404), and a robots.txt that allows crawling. It has no scripts, tracking, analytics, ads or personal data.

Served with GitHub Pages at https://hardwoodlogic.github.io/broken-link-checker-fixture/
